# LunexFX — Creative Studio Website

Premium one-page portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Run locally

1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.
5. Run `npm run build` to create the production build in `dist/`.

## Before publishing

- Replace the Discord links (`https://discord.com/`) with your actual invite URL.
- Replace `hello@lunexfx.com` with your real contact email.
- Replace concept portfolio artwork with your finished project images.
- Replace the clearly marked demo reviews with genuine client reviews, or remove that section until you have them.
- Add real team members / Minecraft avatars when the team is confirmed.
- Update any social profile links.

The portfolio cards are CSS-built visual concepts, not claims of completed client work. The stats communicate creative principles rather than fabricated client counts.
